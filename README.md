# Insurance Analysis

Exploratory data analysis, preprocessing, feature engineering, and insurance-charge prediction using the `insurance.csv` dataset.

## Contents

- `insurance (1).ipynb` - analysis notebook, model training, evaluation, and a Gradio prediction interface
- `insurance.csv` - source dataset used by the notebook
- `requirements.txt` - Python dependencies

## Run locally

1. Create and activate a Python environment.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open `insurance (1).ipynb` in Jupyter or VS Code.
4. Run the cells from top to bottom. The final cell starts the Gradio interface.

The notebook expects `insurance.csv` to be in the same directory.

## Notes

The model is intended for demonstration and educational analysis only. Its predictions should not be used for medical, insurance, or financial decisions.
